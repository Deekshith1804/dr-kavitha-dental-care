# Dr. Kavitha Dental Care - Clinic Website

A responsive, dental clinic website built with React, Vite, Framer Motion, and Lucide React icons.

## Clinic Details
- **Clinic Name:** Dr. Kavitha Dental Care
- **Address:** Jaya Hospital, Kamareddy, Telangana, India
- **Phone:** +91 7396222120
- **Direct WhatsApp:** +91 7396222120

## Features
- **Design & Branding:** Minimalist white and teal medical palette with official tooth-and-K logo.
- **Sticky Navigation:** Responsive navigation with clinic branding, quick phone call button, and mobile hamburger drawer.
- **Hero Section:** Features the heading *"A healthier smile starts with care."*, trust badges, and direct call/enquiry CTAs.
- **Service Cards:** Dedicated cards for General Dental Care, Preventive Care, Smile Care, and Consultations.
- **Patient-First About Section:** Honest and compassionate care philosophy located within Jaya Hospital, Kamareddy.
- **WhatsApp Direct Enquiry:** Interactive enquiry form that validates patient name and phone number, formats a message, and opens WhatsApp directly without storing data on servers.
- **Location & Google Maps:** Click-to-call links (`tel:+917396222120`) and Google Maps search link and preview for Jaya Hospital, Kamareddy.
- **Accessibility & Motion:** Smooth entrance animations powered by Motion with support for `prefers-reduced-motion`.

## Local Development

```bash
# Navigate to the project directory
cd /Users/deekshithgoud/.gemini/antigravity/scratch/dr-kavitha-dental-care

# Start development server
npm run dev
```

Open your browser at `http://localhost:3000` (or the port shown in terminal).

## Production Build

```bash
npm run build
```
The optimized production bundle will be generated in `dist/`.

To preview the production build locally:
```bash
npm run preview
```
